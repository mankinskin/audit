## Functional requirements

1. Extend the guidance Markdown audit with stable finding classes for: missing local target, valid guidance target, local non-guidance target, nested/cross-repository target, external URL, fragment-only link, unsupported dependency kind, unsafe path, and unreadable source/target.
2. A guidance file may reference only the portable guidance corpus or explicitly permitted guidance metadata. Local targets resolving to ticket stores, specification stores, source code, generated implementation artifacts, or unrelated repository files are blocking portability findings.
3. Nested/cross-repository targets must not be silently treated as missing or valid. The audit must record the repository boundary and classify the result according to policy, preserving the existing intentional skip behavior only where the policy explicitly says so.
4. Finding ids, categories, severity, source path, line, raw destination, resolved target, classification, and remediation instructions must be deterministic and machine-readable.
5. The pre-commit hook must fail on blocking portability findings and missing local targets, while preserving external URL and fragment-only handling and the documented `--no-verify` escape hatch.
6. `install-ctl guidance install` consumes the audit contract in detect/inform mode and must not mutate files when blocking findings exist.
7. `install-ctl guidance autofix` is explicit and opt-in. It supports plan/dry-run output, requires a declared scope, applies only safe registered transformations, and refuses ambiguous or destructive fixes.
8. Autofix can consume current hook/audit findings by stable finding id or report file, verifies the source hash before applying, writes atomically, and reruns the audit after applying.
9. Every applied fix reports before/after path or link, transformation kind, source hash, and post-fix audit result. Failed post-fix audit rolls back or returns a non-zero result without claiming success.
10. No ticket/spec/code artifact is installed as a remediation for a portability violation; unresolved findings remain explicit blockers.
